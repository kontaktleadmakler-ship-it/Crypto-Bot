## Guarantees
- No live order execution path is exposed by the v24.6 platform.
- Binance adapter is simulation-only and reports `liveExecution: false`.
- ML modules are evaluators; they do not place orders.
- B13 journal is append-only and hash chained.
- Replay is deterministic and sequence checked.
- Paper/Shadow portfolio supports BTCUSDT, ETHUSDT, SOLUSDT, BNBUSDT, XRPUSDT and additional symbols.
- Exposure, position and maintenance-margin/liquidation controls are included.
- Reports: HTML, PDF, CSV and JSON.

## Validation
Run `npm test` in an environment with Node.js >= 18.
The repository test path does not require network access.
