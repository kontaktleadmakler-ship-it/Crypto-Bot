# v24.7 Institutional Agent Suite

v24.7 adds the missing specialist AI evaluators to the v24.6 Signal/Paper/Shadow platform.

## Agents
- Risk Supervisor: independent risk decision; hard limits remain authoritative.
- Portfolio Allocation: scales requested multi-asset weights to portfolio limits.
- Anomaly Detection: evaluates spread, slippage, latency and candle-delay anomalies.
- Liquidity Agent: evaluates spread and order-book depth.
- Exit Evaluation: evaluates HOLD/REDUCE/EXIT recommendations for existing positions.
- Strategy Evaluation: classifies strategy health from expectancy, Sharpe, drawdown, OOS and drift inputs.
- Meta Supervisor: combines evaluator outputs into PAPER_OK, REDUCE_RISK or NO_TRADE.

## Existing ML stack
DQN, Double DQN, Dueling DQN, PER, feature pipeline/store, regime classifier and drift detection remain available.

## Safety
- No agent can enable live order execution.
- Hard risk controls are not overridable by agents.
- The runtime remains Signal -> Paper -> Shadow.
- Agent decisions are suitable for logging, audit and evaluation.

## Runtime integration
The runtime evaluates the suite before the existing DQN veto and downstream execution path. Only hard supervisor blocks are enforced at the signal gate; other agent outputs remain observable and auditable.
