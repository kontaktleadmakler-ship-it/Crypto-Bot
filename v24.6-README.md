# Trading Bot v24.6 — Institutional Edition

## Operating model
Signal → Paper → Shadow. No live order execution is implemented.

## B13
Append-only execution journal, hash chain, snapshots, deterministic replay, duplicate/missing event detection and 32 crash/restart scenarios.

## B14
Institutional backtesting engine with fees, slippage, funding, leverage/margin controls, TP/SL, portfolio accounting, multi-timeframe hook and institutional metrics.

## B14.3
10,000-run Monte Carlo engine, walk-forward windows and out-of-sample validation.

## B15
Feature store/pipeline, DQN/PPO evaluation, reward engine, confidence scoring, regime classifier and drift detection. ML is evaluation-only and never places trades.

## B16
Metrics registry, health monitoring, dashboards, alert triggers, kill-switch/replay/API/drawdown/daily-loss/circuit-breaker alerts.

## v24.6
Institutional paper/shadow portfolio across BTC, ETH, SOL, BNB, XRP and extensible symbols; correlation/exposure/position limits; simulated Binance Futures Testnet adapter; HTML/CSV/JSON reporting with PDF-ready reporting pipeline.

## Safety invariant
The testnet adapter is explicitly simulated and reports `liveExecution: false`. No module in v24.6 submits live exchange orders.
