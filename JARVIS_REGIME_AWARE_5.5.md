# JARVIS 5.5 — Regime-Aware Intelligence

Adds a read-only regime analytics layer to the JARVIS dashboard.

## Regimes
- BULL_TREND
- BEAR_TREND
- RANGING
- HIGH_VOLATILITY
- CRISIS

## Analytics
- regime-level hit rate
- average outcome return
- Sharpe
- maximum drawdown
- action performance per regime
- agent performance per regime
- PASS/VETO outcome averages
- average agent score

## Safety
This layer is analytical only. It cannot place orders, alter risk gates, promote models, or change live execution state.
